# HR Analytics – SQL Server Project

## Project overview
This project uses SQL Server (T-SQL) to explore a sample HR dataset and answer business questions about workforce composition, employee compensation, and hiring patterns.

## Business questions
- How many employees and departments are represented in the dataset?
- Which departments have the largest workforces?
- How do average salaries differ by department and from the company average?
- Who are the highest-paid employees in each department?
- Which departments have the widest salary gaps?
- How has hiring activity varied by year and department?
- Which recent hires earn substantially more than their department average?

## Dataset
The project uses two related tables:

| Table | Description |
|---|---|
| `Departments` | Department ID, department name, and location |
| `Employees` | Employee ID, name, department, salary, age, hire date, and job title |

The dataset contains 20 sample employee records across 6 departments. Names and records are sample data for SQL practice; they should not be interpreted as a real company's employee records.

## SQL concepts demonstrated
- Database and table creation
- Primary keys and foreign keys
- Data insertion and joins
- Aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
- `GROUP BY` and `HAVING`
- `CASE` expressions
- Common Table Expressions (CTEs)
- Subqueries
- Window functions: `AVG() OVER`, `DENSE_RANK()`, `RANK()`, `LAG()`
- Stored procedures and parameters

## How to run
1. Open SQL Server Management Studio (SSMS).
2. Open `sql/hr_analytics.sql`.
3. Execute the script using a SQL Server account with permission to create a database.
4. Review the result sets generated by each analysis query.

The script creates `HR_Analytics_Project`, creates and populates the tables, and runs the analysis queries. It also creates a stored procedure named `GetTopEmployees`.

## Notes and limitations
- This is a small sample dataset intended to demonstrate SQL analysis techniques.
- The data is not suitable for making real compensation, hiring, or workforce decisions.
- Salary differences and age patterns show associations in this sample; they do not establish causes or prove compensation inequality.
- The script uses SQL Server-specific T-SQL syntax
